📖 Petit Glossaire Technique

Quelques définitions simples pour comprendre le jargon technique utilisé dans ce portfolio.

eCRF (Cahier d'Observation)
Formulaire numérique ultra-sécurisé utilisé en recherche clinique pour recueillir les données de santé des patients.
Audit Trail
Traçabilité inviolable enregistrant silencieusement chaque action (qui, quand, quoi) pour garantir l'intégrité médico-légale des données.
RPA (Automatisation Robotisée)
Robots logiciels programmés pour effectuer des tâches répétitives à la place d'un humain (comme cliquer ou copier-coller des données).
PWA (Progressive Web App)
Application web moderne qui peut s'installer sur un smartphone et fonctionner même sans aucune connexion internet.
OCR (Reconnaissance Optique)
Technologie permettant à l'ordinateur d'"extraire" et de lire automatiquement le texte présent dans une image ou un PDF scanné.
Kanban
Méthode de gestion très visuelle utilisant des colonnes (ex: À faire, En cours, Terminé) pour suivre facilement l'avancée d'un projet ou d'un dossier.
Git & DevOps
Système agissant comme une "machine à remonter le temps" pour le code informatique. Il sauvegarde l'historique et permet d'annuler les erreurs facilement.
JSON
Format de fichier texte léger et universel, utilisé pour faire communiquer facilement différentes applications informatiques entre elles.
Frameworks (Tkinter, Flet...)
Ce sont des "boîtes à outils" pour les programmeurs. Ils permettent de concevoir les fenêtres, boutons et interfaces visuelles d'un logiciel.
SQLite / IndexedDB
Des bases de données "locales", directement embarquées dans l'ordinateur ou le navigateur, sans avoir besoin de faire appel à un serveur externe.
